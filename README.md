OrangeHRM Cucumber Automation Framework

Project Overview

This project is an automation testing framework developed using Java, Selenium WebDriver and Cucumber BDD. It automates the login and employee management functionalities of the OrangeHRM web application.

Technologies Used

* Java
* Selenium WebDriver
* Cucumber BDD
* Gherkin
* TestNG
* Maven
* GitHub

Test Scenarios

1. Verify OrangeHRM login functionality.
2. Validate login using valid credentials.
3. Navigate to the Add Employee page.
4. Add multiple employees using Scenario Outline.
5. Capture and validate employee IDs.
6. Verify employee creation functionality.

Framework Features

* Behaviour Driven Development (BDD).
* Gherkin feature files.
* Scenario and Scenario Outline.
* Data-driven testing using Examples.
* Reusable step definitions.
* Automated browser testing using Selenium WebDriver.

Application Under Test

OrangeHRM: https://orangehrm.qedgetech.com/

Project Structure

* Feature Files – Contains test scenarios.
* Step Definitions – Contains Java automation code.
* Test Runner – Executes Cucumber scenarios.
* Maven – Manages project dependencies.

How to Execute

1. Clone or download the repository.
2. Import the project into Eclipse or IntelliJ IDEA.
3. Update Maven dependencies.
4. Configure the browser driver if required.
5. Execute the Cucumber Test Runner.
